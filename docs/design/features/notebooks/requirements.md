# Requirements: the product notebooks

EARS (Mavin et al., RE'09, doi:10.1109/RE.2009.9). Every requirement names the gate that fails when it is violated.
The notebooks are the product's didactic layer (CAOS_MANAGE `conventions/product-notebooks.md`, Felipe 2026-10-20): the
folder `notebooks/` holds two trees, `en/` and `es/`, with the same notebooks at the same relative paths, by topic and from
simple to complex (level 1 fundamentals, 2 the method in practice, 3 state of the art, 4 beyond it). They import the
product's methods and never re-implement them. The static check is `scripts/check_notebooks.py` (CI and local); the
execution is `scripts/run_notebooks.py --check`, a local release gate that never runs in CI (ADR-0074). The guide is
[`docs/guides/08_notebooks.md`](../../../guides/08_notebooks.md).

|---|---|---|
| NB-026 | THE committed notebook set SHALL pass the static check, SHALL hold the same 18 notebooks in English and Spanish in seven topics at the levels as committed, and every notebook SHALL import the product's methods from the pipeline and define none of the engine's names. | `tests/test_notebooks_chancadem.py::test_the_committed_set_is_mirrored_in_seven_topics_and_passes_the_static_check`, `tests/test_notebooks_chancadem.py::test_every_notebook_imports_the_pipeline_and_defines_no_engine_name` |
| NB-027 | THE notebook trees SHALL hold no notebook of the template's example, neither by its path nor by its engine import. | `tests/test_notebooks_chancadem.py::test_the_notebook_trees_hold_no_notebook_of_the_template_example` |
| NB-037 | THE oracles module (`data-pipeline/pipeline/oracles.py`) SHALL compute the Rosin-Rammler passing and its inverse, the Bond energy and power and the mass closure in closed form, and SHALL share no code with the engine. | `tests/test_oracles.py::test_the_inverse_law_and_the_f80_closed_form`, `tests/test_oracles.py::test_the_oracle_shares_no_code_with_the_engine` |
| NB-038 | THE notebooks SHALL import the oracles from `pipeline.oracles` and define none of their names; five notebooks per language use an oracle today. | `tests/test_notebooks_chancadem.py::test_the_oracles_are_imported_by_the_notebooks_that_use_them_and_defined_in_none` |
| NB-040 | THE figure cell of the case-matrix notebook (level 2, topic 01) that is titled Case S01 SHALL run that case by binding it itself, and its committed output SHALL carry the power S01 draws at the tightest and the widest setting, read from `data/derived`. | `tests/test_notebooks_chancadem.py::test_the_figure_cell_of_the_case_matrix_binds_its_case_and_carries_that_case_numbers` |
| NB-041 | IF `run_notebooks.py --check` is given no temp root (neither `--tmp DIR` nor the environment variable `CAOS_TEMP_ROOT`), THEN THE runner SHALL stop with exit 2 and the message `run_notebooks: --check needs a temp root: pass --tmp DIR or set CAOS_TEMP_ROOT (the device's temp root)`, executing nothing. | `tests/test_run_notebooks.py::test_adversarial_check_without_a_temp_root_stops_with_exit_2` |
| NB-042 | THE `--check` run SHALL write its copies only to a fresh folder under the temp root (`--tmp` over `CAOS_TEMP_ROOT`), remove it after the run, and write nothing in the repository or the system temp folder. | `tests/test_run_notebooks.py::test_adversarial_check_writes_only_under_the_temp_root_and_removes_it` |
| NB-043 | THE public names of a method package declared in `product.json` `method_packages` SHALL be the top-level `def`, `async def` and `class` names not starting with `_` of the `.py` files under its installed folder, without those under a `tests` folder or in a module whose own name starts with `_` (`__init__.py` stays), read with `ast` and never by importing the package. | `tests/test_check_notebooks.py::test_adversarial_the_public_names_of_a_method_package_are_read_without_importing_it` |
| NB-044 | NO notebook SHALL define a function or a class that a method package defines; THE finding SHALL name the notebook, the cell, the name and the package. | `tests/test_check_notebooks.py::test_adversarial_a_notebook_that_defines_a_method_package_name_is_found` |
| NB-045 | WHERE `method_packages` is absent or empty THE check SHALL behave as at 0.10.000; IF a declared package is not installed, THEN `check_notebooks.py` SHALL print the info line `check_notebooks: <name> not installed here; its names are checked by run_notebooks.py` and not fail, and `run_notebooks.py` SHALL fail before any notebook executes. | `tests/test_check_notebooks.py::test_adversarial_a_method_package_that_is_not_installed_is_info_in_the_static_check` |
| NB-046 | IF a declared method package has no exact `name==version` line (extras allowed) in `notebooks/requirements.txt`, THEN the check and the runner SHALL each report it as a finding. | `tests/test_check_notebooks.py::test_adversarial_a_method_package_without_a_pin_is_found` |
| NB-047 | WHERE `check_notebooks.py --pypi` is given, THE check SHALL read `https://pypi.org/pypi/<name>/<version>/json` for the pin of each method package and fail on anything but HTTP 200, naming the URL and the status; no CI step SHALL pass `--pypi`, and without it THE check SHALL make no network call. | `tests/test_check_notebooks.py::test_adversarial_the_pypi_check_fails_on_anything_but_200` |
